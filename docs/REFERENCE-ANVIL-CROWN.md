# REFERENCE — "THE ANVIL AND CROWN" (Gemini/Lyria, one pass)

The founder's quality benchmark: made in Gemini only, "amazing imho."
Measured profile (desk bench, 2026-11-08):

- Duration 158.1 s · 44.1 kHz stereo · vocals throughout.
- **Tempo 69.8 BPM — identical in the global read and in ALL five
  30-second windows.** Zero drift. (69.8 reads as the half-time of a
  ~140 double-time feel.) One pass = one clock, everywhere.
- **Stereo: L/R correlation 0.9293 · side RMS −28.8 dBFS** — wider
  than our Stereo Law v2 produced (0.9527 / −32.0). The bar, in numbers.
- Dynamics alive: 30-s window RMS −15.8 / −13.4 / −13.1 / −13.8 /
  −15.7 dBFS — sections breathe (cf. Brightmoor v1's flat ±0.7 dB).
- Sample peak +0.67 dBFS (MP3 inter-sample overs; consumer master).

## What the house takes from it

1. Plan-first, single-pass generation is why it coheres (Lyria plans
   sections, then renders the song as one performance). Our clip model
   approximates this via motif-locking + continuation chaining
   (probe running with the v3 build, 2026-11-08).
2. House targets henceforth, from this profile: tempo drift across
   windows ≈ 0; side RMS ≥ −29 dBFS; window RMS must MOVE with the
   sections (a flat line is a Frankenstein symptom).
